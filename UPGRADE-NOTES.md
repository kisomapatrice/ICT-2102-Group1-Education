# Bright Future Secondary School — Website Upgrade

This package upgrades the existing eight-page Group 1 Education website while preserving its original page structure and school identity.

## Included
- Responsive visual refresh in `assets/css/styles.css`
- Required external JavaScript entry point: `js/script.js` (loaded with `defer` on all HTML pages)
- Interactive course catalogue, comparison table and illustrative fee calculator on Academics
- Student registration demonstration with JavaScript validation and on-page feedback
- Video and audio player examples on Student Life
- Existing pages, assets and original JavaScript retained

## Important notes
- Course names and fee figures in the interactive assignment demonstration are illustrative, not an official school prospectus or fee schedule.
- The registration form is client-side only. It does not transmit or store personal information.
- The video/audio examples use public sample media URLs. Replace them with school-approved media before presenting the site as an official school publication.

## Deploy to GitHub Pages
1. Extract this ZIP.
2. Open the existing `ICT-2102-Group1-Education` repository.
3. Upload the contents of the extracted project root (not the enclosing folder) to the repository root.
4. Commit the update and allow GitHub Pages to redeploy.


## Visual polish update
- Added a responsive school-information table to the homepage. On narrow screens, each row becomes a readable stacked information card.
- Refined typography, spacing, contrast, navigation, cards, focus states and mobile layouts across all pages.
- The complete `assets/` directory is included; upload it as a folder, preserving its internal structure.
