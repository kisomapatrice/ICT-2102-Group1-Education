# Group 1 Education — Pre-submission Test Checklist

## Pages and navigation
- [ ] Open all nine HTML pages directly.
- [ ] Follow each header and footer link; no link should lead to a missing page.
- [ ] Check the active navigation item on each page.
- [ ] Test the mobile menu with mouse, touch, keyboard, and Escape.
- [ ] Confirm there is no horizontal page overflow at desktop, tablet, or phone widths.

## Visual layout
- [ ] Review at 1920px, 1440px, 1280px, 1024px, 768px, and 390px widths.
- [ ] Confirm headings, body text, labels, and buttons remain readable.
- [ ] Confirm registration fields and side cards do not overlap or cover one another.
- [ ] Confirm images crop well, have descriptive alt text, and have a fallback when unavailable.
- [ ] Confirm focus indicators remain visible and reduced-motion preferences are respected.

## Interactive features
- [ ] Search the programme catalogue and combine search with each category filter.
- [ ] Filter the timetable by every day and return to all days.
- [ ] Filter the gallery, open an image, close the lightbox, and test Escape.
- [ ] Calculate totals for one learner and multiple learners; test zero and empty fields.
- [ ] Tick the admissions checklist and review registration instructions.
- [ ] Test required fields, email/phone patterns, password length, and password match.
- [ ] Test feedback rating, required message length, character counter, and reset action.
- [ ] Play the audio and video on an internet-connected browser.
- [ ] Follow external educational links and confirm they open the expected destination.

## Before publishing
- [ ] Review `git status` and the staged diff before committing.
- [ ] Confirm all group members' roles and add their names where required by the lecturer.
- [ ] Use authoritative sources for any institution-specific information.
- [ ] If online registration is required, implement and test the server-side endpoint, database handling, validation, and security separately.
