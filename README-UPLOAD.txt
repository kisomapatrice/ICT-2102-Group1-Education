================================================

PACKAGE CONTENTS
- index.html                 Home page (upload this at the website root)
- about.html                 Our School
- academics.html             Academics
- admissions.html            Admissions and WhatsApp enquiry form
- student-life.html          Student Life
- news.html                  News and Updates
- gallery.html               Interactive image gallery
- contact.html               Contact form, click-to-call and location map
- assets/css/styles.css      Responsive layout and visual design
- assets/js/main.js          Navigation, tabs, forms, gallery and interactions

UPLOAD INSTRUCTIONS
1. Open your hosting file manager or FTP client.
2. Open the website document root (commonly public_html, htdocs or www).
3. Upload index.html and all the other .html files directly into that root.
4. Upload the complete assets folder, keeping its folders and filenames unchanged.
5. Make sure index.html is at the root level, not one folder deeper.
6. Open the website address and test Home, About, Academics, Admissions, Student Life,
   News, Gallery and Contact on desktop and on a phone.
