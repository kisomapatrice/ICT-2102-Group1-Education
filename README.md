# ICT-2102 Group 1 – Educational Web Platform

Welcome to the official repository for **ICT-2102 Group 1**. This website serves as an interactive educational hub featuring course modules, learning resources, team profiles, an FAQ section, and a contact form.


## 🌐 Live Website
Access our published platform on GitHub Pages:
👉 **[https://kisomapatrice.github.io/ICT-2102-Group1-Education/](https://kisomapatrice.github.io/ICT-2102-Group1-Education/)**


## 🛠️ Features & Technologies Used

### Key Features
* **Responsive Navigation:** Interactive navigation menu designed for both desktop and mobile devices.
* **Module Search Filter:** Live search bar to quickly filter educational resources by topic.
* **FAQ Accordion:** Expandable questions and answers covering project details.
* **Contact Form:** Interactive form with real-time feedback upon submission.

### Tech Stack
* **HTML5:** Web structure and semantic layout
* **CSS3:** Responsive styles, Flexbox, CSS Grid, and custom variables
* **JavaScript (ES6):** Dynamic search filtering, mobile navigation toggle, and form handling
* **Git & GitHub:** Version control, collaboration, and cloud backup
* **GitHub Pages:** Automated web hosting
