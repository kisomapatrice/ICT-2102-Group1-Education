# Group 1 Education — Team Work Plan

The group has four complementary roles. Agree on the named member for each role in class and rotate review duties so every member gains practical experience.

## Roles

1. **HTML Developer** — maintains page structure, navigation, semantic elements, tables, multimedia elements, and forms.
2. **Content Designer** — checks wording, learning-area descriptions, educational resources, accuracy, and content consistency.
3. **Tester** — checks links, form validation, filters, calculator results, responsive layouts, keyboard access, and browser errors.
4. **Presenter / Team Leader** — coordinates tasks, records decisions, checks progress, and presents the final project.

## Working agreement

- Work in the existing GitHub repository; do not create an unrelated second project.
- Keep page links relative and preserve the shared CSS and JavaScript files.
- Before editing, pull or check the latest team changes.
- After editing, test every affected page and check both desktop and mobile widths.
- Review the diff before committing. Use clear commit messages that describe a single change.
- Do not publish invented institutional fees, dates, admissions rules, or contact details as official information.
- Do not describe registration as online submission until a secure server-side submission service has been implemented and tested.
