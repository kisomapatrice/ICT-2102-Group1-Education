Frequently Asked Questions

Find quick answers about our Group 1 Education Project.

What is the goal of this website?

This project fulfills the ICT 2102 requirement by demonstrating competence in local version control (Git), remote hosting (GitHub), and live deployment (GitHub Pages).

How can teammates contribute?

Teammates added as GitHub collaborators can clone the repository, make edits locally in VS Code, commit, and push updates directly to the main branch.

Is this website responsive?

Yes, the layout uses modern CSS Grid, Flexbox, and media queries to automatically adjust to smartphones, tablets, and desktop computers.
