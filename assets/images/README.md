# Photographic backgrounds and gallery images

The homepage hero uses a full-width photographic background with a transparent forest-green overlay so the heading and calls to action sit over the image. Each secondary page has a different photographic hero, and the three home feature cards have their own separate photographs. The gallery uses six distinct photographs. Image URLs use Unsplash image delivery, so an internet connection is required for photographs to load. The CSS uses a designed deep-green fallback colour if a background image cannot be reached.

Keep each page's photo choice distinct when future coursework features are added. Use the same CSS image treatment and text-overlay pattern rather than repeating a photograph across pages.
